1. 서비스의 내용

사용자는 문장 안의 여러 부분을 가림으로 지정하고, 각 가림의 숙련 상태와 복습 일정을 기록할 수 있습니다. 데이터는 기기, 동기화 코드 또는 로그인 계정 중 사용자가 선택한 방식으로 저장됩니다.

2. 이용과 계정

  • 기기 저장과 동기화 코드 저장은 로그인 없이 사용할 수 있습니다.
  • 계정 동기화에는 Google 등 제공되는 외부 로그인 서비스가 필요합니다.
  • 사용자는 자신의 계정과 동기화 코드를 안전하게 관리해야 합니다.
  • 동기화 코드를 공유해 발생한 접근은 서비스가 계정 소유자와 구분할 수 없습니다.

3. 사용자가 만든 내용

사용자는 자신이 입력한 문장과 학습 자료에 대한 권리와 책임을 가집니다. 타인의 개인정보, 저작권을 침해하는 자료 또는 불법적인 내용을 저장해서는 안 됩니다. 서비스는 학습 기능과 동기화 제공에 필요한 범위에서만 해당 내용을 처리합니다.

4. 금지되는 이용

  • 서비스 또는 다른 사용자의 데이터에 무단으로 접근하는 행위
  • 과도한 자동 요청, 악성 코드 또는 보안 우회로 서비스 운영을 방해하는 행위
  • 법령이나 제3자의 권리를 침해하는 내용을 저장·전송하는 행위
  • 서비스를 사칭하거나 로그인 정보를 부정하게 취득하는 행위

5. 서비스 변경과 중단

안정성, 보안 또는 기능 개선을 위해 서비스 내용이 변경될 수 있습니다. 점검, 장애, 외부 서비스의 변경이나 불가항력으로 일부 기능이 일시 중단될 수 있으며, 중요한 변경은 가능한 범위에서 서비스 화면이나 이 페이지를 통해 알립니다.

6. 데이터 보관과 종료

사용자는 언제든지 사용을 중단할 수 있습니다. 로그아웃만으로 서버 데이터가 삭제되지는 않습니다. 계정 또는 서버 데이터 삭제는 도움말의 삭제 절차에 따라 요청할 수 있습니다. 기기 저장 데이터는 사용자가 브라우저·앱 저장소를 직접 삭제해야 합니다.

7. 책임의 범위

서비스는 학습을 돕는 도구이며 특정 시험 결과나 학습 성과를 보장하지 않습니다. 사용자는 중요한 자료를 별도로 백업할 책임이 있습니다. 관련 법령이 허용하는 범위에서, 무료로 제공되는 서비스의 일시적인 중단이나 사용자의 계정·동기화 코드 관리 소홀로 발생한 손해에 대한 책임은 제한됩니다.
