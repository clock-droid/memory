도움말 및 문의

여러 가림을 한 카드에 묶어 만들고, 기억나지 않은 가림만 다시 학습하는 암기장입니다. 저장이나 로그인 문제를 해결할 수 없는 경우 아래 연락처로 알려주세요.

이메일로 문의

자주 묻는 질문

  • 기기 저장은 다른 기기에서 볼 수 있나요? 아니요. 기기 저장은 현재 브라우저나 앱 안에만 남습니다. 여러 기기에서 사용하려면 계정 저장을 선택하세요.
  • 동기화 코드는 어떻게 관리해야 하나요? 코드를 아는 사람은 같은 암기장을 불러올 수 있습니다. 비밀번호처럼 보관하고 공개된 장소에 올리지 마세요.
  • Google 로그인 후 기존 카드가 사라지나요? 계정으로 옮기기를 선택하면 현재 카드를 계정에 복사하며, 원래 저장본은 자동으로 삭제하지 않습니다.
  • 카드 하나에서 일부만 다시 공부할 수 있나요? 네. 학습 중 기억나지 않은 가림을 선택하면 해당 가림만 다시 학습 대상으로 남습니다.
  • 로그인만 해제하고 싶어요. 설정의 ‘이 기기에서 로그아웃’을 사용하세요. 다른 기기의 데이터와 서버 저장본은 유지됩니다.

계정 및 데이터 삭제

삭제 요청 이메일의 제목을 [데이터 삭제 요청]으로 적고, 아래 정보를 포함해 주세요. 본인 확인에 필요한 최소한의 정보만 요청합니다.

  1. 계정 저장: 로그인에 사용한 Google 이메일 주소
  2. 동기화 코드 저장: 삭제할 동기화 코드
  3. 삭제 범위: 계정 전체 또는 특정 저장본

확인이 끝나면 관련 인증 정보와 서버 학습 데이터를 삭제합니다. 기기 저장 데이터는 브라우저의 사이트 데이터 삭제 또는 앱 삭제를 통해 사용자가 직접 지울 수 있습니다.
